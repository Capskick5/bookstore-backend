    users {
        bigint id PK
        varchar email UK

        varchar full_name

    categories {

    books {
        bigint id PK
        varchar title

Đọc sơ đồ thế nào (cho người mới): mỗi ô là một bảng. Đường nối thể hiện quan hệ. Ví dụ users ||--o{ orders nghĩa là 1 user có nhiều order, mỗi order thuộc về đúng 1 user (qua cột user_id). orders ||--o{ order_items nghĩa là 1 đơn gồm nhiều dòng sản phẩm. UK = unique (không trùng), FK_UK = vừa khóa ngoại vừa duy nhất (mỗi user chỉ 1 giỏ).

Lưu ý: Qdrant (vector) và MongoDB (chunk/ảnh) thuộc service RAG của P5, KHÔNG nằm trong sơ đồ quan hệ này vì chúng không phải database quan hệ. File SQL thật: docs/erd/schema.sql.
