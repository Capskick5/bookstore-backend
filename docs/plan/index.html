Tiến độ: 0%
📖 Giải thích thuật ngữ (đọc cái này trước)
Skeleton (bộ khung): phần nền tối thiểu để app chạy được, chưa có tính năng.
Spring Boot: framework Java để viết API backend.
Maven (pom.xml): công cụ build + quản lý thư viện cho Java.
Endpoint: một địa chỉ API, vd POST /auth/login.
JWT: "vé thông hành" — đăng nhập xong nhận vé, lần sau đưa vé là được vào.
RBAC / phân quyền: phân biệt ADMIN và CUSTOMER được làm gì.
Docker / docker-compose: chạy sẵn database (Postgres, Qdrant, Mongo) trong "hộp" bằng 1 lệnh, khỏi cài tay.
Migration (Flyway): file SQL ghi lại cách tạo bảng — ai chạy cũng ra database giống hệt nhau.
Seed data: dữ liệu mẫu nạp sẵn (1 admin + vài cuốn sách) để test.
Swagger: trang web tự sinh để xem & thử API, có nút dán token.
CI (GitHub Actions): "người máy" tự build + test mỗi lần push để bắt lỗi sớm.
.env: file chứa mật khẩu/khóa bí mật — KHÔNG đẩy lên GitHub.
Thứ tự làm: P6 làm B1 trước (tạo repo + docker chạy DB) → P1 mới nối được database. Hai người làm song song phần còn lại. Việc nào cần việc kia thì ghi rõ "cần ... xong trước".
